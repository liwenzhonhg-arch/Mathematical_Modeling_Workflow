# 动态规划 (Dynamic Programming)

## 方法简介

动态规划将复杂的多阶段决策问题分解为一系列相互关联的子问题，通过存储子问题的解避免重复计算，从而高效求得全局最优解。核心思想是**最优子结构**和**重叠子问题**。

## 适用场景

- 多阶段决策过程：每一步做一个决策，影响后续状态
- 问题具有最优子结构：全局最优解包含子问题的最优解
- 存在重叠子问题：不同决策路径会重复遇到相同子问题
- 典型场景：最短路径、背包问题、资源分配、序列比对

## 基本原理

**贝尔曼最优性原理**：最优策略的任何子策略也是最优的。

状态转移方程（以背包问题为例）：

$$f(i, w) = \max\{f(i-1, w), \; f(i-1, w-w_i) + v_i\}$$

其中 $f(i, w)$ 表示前 $i$ 个物品、容量为 $w$ 时的最大价值。

求解步骤：
1. **定义状态**：明确子问题的参数化描述
2. **建立转移方程**：当前状态如何由前驱状态推导
3. **确定边界条件**：最小子问题的直接解
4. **确定计算顺序**：自底向上（递推）或自顶向下（记忆化搜索）

时间复杂度通常为 $O(\text{状态数} \times \text{每个状态的转移代价})$。

## Python 实现要点

```python
# 0-1背包（自底向上）
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            dp[i][w] = dp[i-1][w]
            if w >= weights[i-1]:
                dp[i][w] = max(dp[i][w], dp[i-1][w-weights[i-1]] + values[i-1])
    return dp[n][capacity]
```

- 自底向上递推实现简单，适合状态空间规整的问题
- 记忆化搜索（`functools.lru_cache`）适合状态空间稀疏的问题
- 滚动数组优化空间：当转移只依赖前一行时，用一维数组即可

## 国赛常见应用举例

- **资源分配问题**：多阶段预算分配使总收益最大化
- **最短路径/最优路线**：多段图上的最优通行方案
- **库存管理**：多周期进货-销售的最优策略
- **2019-B 天际线问题变体**：涉及多阶段决策的排列优化
