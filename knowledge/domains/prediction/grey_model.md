# 灰色预测 GM(1,1)

## 方法简介

灰色预测是邓聚龙教授提出的灰色系统理论中的核心方法，GM(1,1) 表示一阶微分方程、单变量模型。其最大优势是对小样本、贫信息系统具有良好的预测能力，不要求数据服从特定分布，建模门槛低。

## 适用场景

- 数据量少（4~10 个即可建模）
- 数据呈近似指数增长或衰减趋势
- 缺乏明确机理模型的灰色系统预测
- 适合短期预测，长期预测精度下降明显

## 基本原理

设原始序列 $x^{(0)} = (x^{(0)}(1), x^{(0)}(2), \ldots, x^{(0)}(n))$，对其做一次累加生成（AGO）：

$$x^{(1)}(k) = \sum_{i=1}^{k} x^{(0)}(i)$$

建立一阶微分方程（白化方程）：

$$\frac{dx^{(1)}}{dt} + a x^{(1)} = b$$

其中 $a$ 为发展系数，$b$ 为灰作用量。用最小二乘法求解：

$$\hat{\boldsymbol{u}} = \begin{bmatrix} a \\ b \end{bmatrix} = (B^T B)^{-1} B^T Y$$

求解微分方程得时间响应函数：

$$\hat{x}^{(1)}(k+1) = \left(x^{(0)}(1) - \frac{b}{a}\right)e^{-ak} + \frac{b}{a}$$

再做累减还原（IAGO）得预测值 $\hat{x}^{(0)}(k+1) = \hat{x}^{(1)}(k+1) - \hat{x}^{(1)}(k)$。

精度检验：残差检验、后验差比值 $C < 0.35$ 为好、小误差概率 $P > 0.95$ 为好。

## Python 实现要点

- 无成熟第三方库，通常手动实现（仅需 `numpy` 矩阵运算）
- 关键步骤：累加生成 -> 构造矩阵 $B$ 和 $Y$ -> 最小二乘求参数 -> 求解还原
- 注意检查 $|a| < 2$ 以确保模型有效
- 可扩展为 GM(1,N)（多变量）或新陈代谢 GM(1,1)（滚动更新数据）

## 国赛常见应用举例

- **能源消耗预测**：小样本下预测未来几年的能源需求
- **2017 B 题（拍照赚钱）**：灰色预测用户行为趋势
- **交通流量预测**：短期数据下的道路车流量预测
