# 神经网络预测

## 方法简介

神经网络通过模拟生物神经元的连接方式，构建多层非线性映射模型，具有强大的函数逼近能力。在数学建模中常用 BP 神经网络（反向传播）和 LSTM（长短期记忆网络）进行回归预测，适合处理复杂非线性关系。

## 适用场景

- 自变量与因变量之间关系高度非线性
- 数据量较大（至少数百条以上）
- 传统回归或时间序列方法精度不足时作为提升手段
- 多维输入、复杂时序依赖的预测问题

## 基本原理

以 BP 神经网络为例，包含输入层、隐藏层、输出层。前向传播计算：

$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}, \quad a^{(l)} = f(z^{(l)})$$

其中 $f$ 为激活函数（ReLU、Sigmoid 等）。损失函数（均方误差）：

$$L = \frac{1}{2n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

反向传播通过链式法则计算梯度并更新权重：

$$W^{(l)} \leftarrow W^{(l)} - \eta \frac{\partial L}{\partial W^{(l)}}$$

LSTM 在此基础上引入遗忘门 $f_t$、输入门 $i_t$、输出门 $o_t$，解决长序列梯度消失问题：

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$$

## Python 实现要点

- BP 神经网络：`sklearn.neural_network.MLPRegressor` 快速实现，或用 `PyTorch` 自定义结构
- LSTM：使用 `torch.nn.LSTM` 或 `keras.layers.LSTM`
- 数据预处理关键：归一化（MinMaxScaler）、滑动窗口构造样本
- 注意过拟合：使用 Dropout、早停（EarlyStopping）、交叉验证
- 超参数调优：学习率、隐藏层数、神经元数量、batch_size

## 国赛常见应用举例

- **2021 C 题（生产企业原材料订购）**：用 LSTM 预测原材料价格走势
- **空气质量预测**：多维气象因子输入的 BP 神经网络预测 AQI
- **交通流量预测**：LSTM 捕捉时序周期性进行短期预测
