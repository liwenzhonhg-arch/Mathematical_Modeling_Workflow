# 回归分析

## 方法简介

回归分析是通过建立自变量与因变量之间的数学关系模型，实现对因变量的预测与解释。根据模型形式可分为线性回归、多元回归、多项式回归、岭回归等。它是数学建模中最基础、最常用的预测方法之一。

## 适用场景

- 变量之间存在明确的因果或相关关系
- 数据量充足且满足基本统计假设（正态性、独立性、等方差性）
- 需要解释自变量对因变量的影响程度

## 基本原理

以一元线性回归为例，模型形式为：

$$y = \beta_0 + \beta_1 x + \varepsilon$$

采用最小二乘法（OLS）求解参数，使残差平方和最小：

$$\min \sum_{i=1}^{n}(y_i - \hat{y}_i)^2 = \min \sum_{i=1}^{n}(y_i - \beta_0 - \beta_1 x_i)^2$$

参数估计公式：

$$\hat{\beta}_1 = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n}(x_i - \bar{x})^2}, \quad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}$$

模型评价指标：$R^2$（决定系数）、调整 $R^2$、F 检验、t 检验。

## Python 实现要点

- 使用 `sklearn.linear_model.LinearRegression` 进行基础回归
- 多重共线性问题用 `statsmodels` 的 VIF 检测，必要时改用岭回归（`Ridge`）或 Lasso
- `statsmodels.api.OLS` 可输出完整统计检验结果（p 值、置信区间），论文写作优先使用
- 注意数据标准化、异常值处理和残差诊断

## 国赛常见应用举例

- **2020 B 题（穿越沙漠）**：用回归分析建立资源消耗与距离的关系模型
- **GDP 与影响因素分析**：多元回归识别关键经济指标
- **气温预测**：基于历史数据的时间趋势回归建模
