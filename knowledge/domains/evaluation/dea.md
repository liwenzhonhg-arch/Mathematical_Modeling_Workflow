# 数据包络分析 (DEA)

## 方法简介

数据包络分析（Data Envelopment Analysis）是由 Charnes 和 Cooper 于 1978 年提出的效率评价方法。它基于线性规划，通过比较同类决策单元（DMU）的多投入多产出数据，评价各 DMU 的相对效率，无需预设投入产出之间的函数关系。

## 适用场景

- 评价同类组织或系统的相对效率（学校、医院、银行等）
- 多投入、多产出的效率评价问题
- 无法确定投入产出之间明确的生产函数
- 希望识别效率前沿面和改进方向

## 基本原理

以 CCR 模型（规模报酬不变）为例，对第 $k$ 个 DMU 求解：

$$\max \theta_k = \frac{\sum_{r=1}^{s} u_r y_{rk}}{\sum_{i=1}^{m} v_i x_{ik}}$$

约束条件：

$$\frac{\sum_{r=1}^{s} u_r y_{rj}}{\sum_{i=1}^{m} v_i x_{ij}} \leq 1, \quad j = 1, 2, \ldots, n$$

$$u_r, v_i \geq 0$$

通过 Charnes-Cooper 变换转化为线性规划。效率值 $\theta_k = 1$ 表示 DEA 有效（在效率前沿面上），$\theta_k < 1$ 表示存在效率损失。

BCC 模型在此基础上增加凸性约束 $\sum_{j=1}^{n} \lambda_j = 1$，可分解为纯技术效率和规模效率。

## Python 实现要点

- 使用 `scipy.optimize.linprog` 求解对偶形式的线性规划
- 也可用 `pyDEA` 或 `deapy` 等专用库
- 需要对每个 DMU 单独求解一次线性规划
- 输出内容：效率值、松弛变量（识别投入冗余或产出不足）、参考集
- 超效率 DEA：允许效率值大于 1，用于有效 DMU 之间的进一步排序

## 国赛常见应用举例

- **2018 B 题（高温作业专用服装）**：DEA 评价不同设计方案的综合效率
- **银行网点效率评价**：投入（员工数、面积）产出（业务量、利润）的效率分析
- **高校科研效率评价**：比较各高校的科研投入产出效率
