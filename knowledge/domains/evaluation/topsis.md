# TOPSIS

## 方法简介

TOPSIS（Technique for Order Preference by Similarity to Ideal Solution）即逼近理想解排序法，通过计算各方案到正理想解和负理想解的距离来进行排序。方案越接近正理想解且越远离负理想解，则越优。它是最常用的多属性决策方法之一。

## 适用场景

- 多方案、多指标的综合评价与排序
- 指标数据可量化（定量评价为主）
- 需要对评价对象进行优劣排序
- 常与 AHP 或熵权法结合确定权重后使用

## 基本原理

**步骤一：标准化**。对决策矩阵 $X = (x_{ij})_{m \times n}$ 进行向量归一化：

$$r_{ij} = \frac{x_{ij}}{\sqrt{\sum_{i=1}^{m} x_{ij}^2}}$$

**步骤二：加权标准化**。$v_{ij} = w_j \cdot r_{ij}$，其中 $w_j$ 为指标权重。

**步骤三：确定理想解**。

$$V^+ = (v_1^+, v_2^+, \ldots, v_n^+), \quad V^- = (v_1^-, v_2^-, \ldots, v_n^-)$$

正理想解取各列最优值，负理想解取各列最差值。

**步骤四：计算距离与贴近度**。

$$D_i^+ = \sqrt{\sum_{j=1}^{n}(v_{ij} - v_j^+)^2}, \quad D_i^- = \sqrt{\sum_{j=1}^{n}(v_{ij} - v_j^-)^2}$$

$$C_i = \frac{D_i^-}{D_i^+ + D_i^-}, \quad C_i \in [0, 1]$$

$C_i$ 越大，方案越优。

## Python 实现要点

- 注意区分正向指标和负向指标（负向指标需取倒数或反转）
- 标准化方式可选向量归一化或极差归一化
- 权重来源：AHP（主观）、熵权法（客观）或组合赋权
- `numpy` 矩阵运算即可完成全流程，无需额外库
- 输出贴近度 $C_i$ 并按降序排列即为最终排名

## 国赛常见应用举例

- **2021 A 题（FAST 主动反射面）**：对调节方案进行 TOPSIS 综合评价
- **水质评价**：多指标水质数据的优劣排序
- **供应商选择**：从多维度对候选供应商进行综合排名
