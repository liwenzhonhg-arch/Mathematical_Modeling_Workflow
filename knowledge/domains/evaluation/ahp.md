# 层次分析法 (AHP)

## 方法简介

层次分析法（Analytic Hierarchy Process）由 Saaty 于 1970 年代提出，是一种将定性问题定量化的多准则决策方法。通过构建层次结构模型，利用专家的两两比较判断来确定各因素的权重，最终实现方案的综合排序。

## 适用场景

- 多准则、多方案的综合评价与决策
- 评价指标难以量化，需要借助主观判断
- 评价体系层次清晰（目标层-准则层-方案层）
- 常与 TOPSIS、熵权法组合使用（主客观组合赋权）

## 基本原理

**步骤一：构造判断矩阵** $A = (a_{ij})_{n \times n}$，其中 $a_{ij}$ 表示指标 $i$ 相对指标 $j$ 的重要程度（1-9 标度），满足 $a_{ij} = 1/a_{ji}$。

**步骤二：求权重向量**。计算判断矩阵最大特征值 $\lambda_{\max}$ 及对应特征向量 $\boldsymbol{w}$：

$$A \boldsymbol{w} = \lambda_{\max} \boldsymbol{w}$$

归一化后即为权重。

**步骤三：一致性检验**。计算一致性比率：

$$CR = \frac{CI}{RI}, \quad CI = \frac{\lambda_{\max} - n}{n - 1}$$

其中 $RI$ 为随机一致性指标（查表），$CR < 0.1$ 通过检验。

## Python 实现要点

- 用 `numpy.linalg.eig()` 计算特征值和特征向量
- 取最大特征值对应的特征向量并归一化为权重
- 注意 RI 表：$n=3$ 时 $RI=0.58$，$n=4$ 时 $RI=0.90$，$n=5$ 时 $RI=1.12$
- 一致性不通过时需调整判断矩阵，可用几何平均法辅助修正
- 建议封装为函数：输入判断矩阵，输出权重和 CR 值

## 通用应用举例

- 城市宜居性评价：构建多层指标体系，AHP 赋权后综合评分
- **选址问题**：对候选地点进行多维度加权排序
