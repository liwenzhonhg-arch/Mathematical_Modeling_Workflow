# 决策树模型

## 方法简介

决策树是一种基于树形结构进行决策的监督学习方法，既可用于分类也可用于回归。它通过递归地选择最优特征进行数据划分，形成从根节点到叶节点的决策规则，具有良好的可解释性。在评价问题中常用于规则提取和决策支持。

## 适用场景

- 需要可解释的分类或评价规则
- 特征之间存在非线性关系和交互效应
- 数据包含离散型和连续型混合特征
- 需要从数据中自动发现分类标准和评价依据

## 基本原理

决策树的核心在于特征选择准则。以 ID3 算法为例，使用信息增益：

$$\text{Gain}(D, A) = H(D) - H(D|A)$$

其中信息熵：

$$H(D) = -\sum_{k=1}^{K} \frac{|C_k|}{|D|} \log_2 \frac{|C_k|}{|D|}$$

条件熵：

$$H(D|A) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} H(D^v)$$

C4.5 改用信息增益比（修正对多值属性的偏好），CART 使用基尼指数：

$$\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2$$

树的生长通过递归选择使不纯度下降最大的特征进行分裂，直至满足停止条件。剪枝（预剪枝、后剪枝）用于防止过拟合。

## Python 实现要点

- `sklearn.tree.DecisionTreeClassifier`（分类）和 `DecisionTreeRegressor`（回归）
- 关键超参数：`max_depth`、`min_samples_split`、`min_samples_leaf`
- `sklearn.tree.export_graphviz` 或 `plot_tree` 可视化决策树结构
- 特征重要性通过 `feature_importances_` 属性获取
- 单棵决策树易过拟合，实战中常升级为随机森林或 XGBoost

## 国赛常见应用举例

- **2020 C 题（信贷策略）**：决策树提取企业信用等级划分规则
- **医疗诊断模型**：根据症状特征自动生成诊断决策路径
- **客户分群**：根据消费行为特征对客户进行分级评价
