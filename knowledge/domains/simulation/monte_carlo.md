# 蒙特卡洛模拟

## 方法简介

蒙特卡洛方法通过大量随机抽样来近似求解确定性或随机性问题。其核心思想是用统计试验的频率来估计概率或期望值，是处理高维积分、不确定性量化和复杂系统仿真的通用工具。

## 适用场景

- 多维积分与概率计算
- 风险评估与不确定性分析
- 复杂系统的行为仿真
- 优化问题的随机搜索

## 基本原理

利用大数定律，用样本均值估计期望：

$$E[g(X)] \approx \frac{1}{N} \sum_{i=1}^{N} g(X_i)$$

其中 $X_i$ 为从目标分布中抽取的随机样本。估计误差为 $O(1/\sqrt{N})$，与维度无关（这是蒙特卡洛在高维问题中的核心优势）。

**经典应用——估计 $\pi$**：在单位正方形中随机撒点，落入内切圆的比例近似 $\pi/4$：

$$\hat{\pi} = 4 \cdot \frac{\#\{x^2 + y^2 \leq 1\}}{N}$$

## Python 实现要点

```python
import numpy as np

# 蒙特卡洛积分: 估计 ∫₀¹ e^x dx
N = 1_000_000
x = np.random.uniform(0, 1, N)
integral_estimate = np.mean(np.exp(x))  # 真实值 e-1 ≈ 1.7183

# 置信区间
se = np.std(np.exp(x)) / np.sqrt(N)
ci = (integral_estimate - 1.96*se, integral_estimate + 1.96*se)

# 方差缩减：对偶变量法
x1 = np.random.uniform(0, 1, N//2)
estimate = 0.5 * (np.mean(np.exp(x1)) + np.mean(np.exp(1 - x1)))
```

提升效率的关键：方差缩减技术（对偶变量、重要性采样、控制变量）可大幅减少所需样本量。
