# 受保护内容与保真流程

## 默认不可改内容

除非当前任务明确要求修正模型或事实，改稿不得改变：

- 行内和独立 LaTeX 数学片段；
- 数值、正负号、百分号、科学计数法与区间端点；
- 单位及其对应数值；
- `\cite`、`\ref`、`\eqref`、`\label`、URL；
- 图表、算法、公式和章节编号之间的对应关系；
- `% MMW-ALGORITHM:`、`% MMW-ID:`、`% MMW-LIMITATION:` 注释；
- 方法合同声明的算法类别、目标、约束、近似和证书等级；
- 结构化结果给出的完成状态、失败状态和不确定性。

## 可改内容

- 句子主干、语序和指代；
- 不改变逻辑的段落合并与拆分；
- 重复解释和空洞过渡；
- 与证据等价的表达；
- 章节内论证顺序，但移动公式或引用前先核对其依赖。

## 保真流程

1. 保存原文件，不覆盖唯一副本。
2. 运行 `audit` 获得表达问题线索。
3. 改写纯文字，不手工重敲公式、数字和引用。
4. 运行 `compare before after`。
5. 比较失败时查看差异类别，恢复无授权变化。
6. 编译 LaTeX，并继续运行项目已有数值审计、方法追踪和 PDF 门禁。

`compare` 是窄门禁，只证明它覆盖的 token 没有增删改；它不能证明段落语义完全等价。因此
仍需人工或 LLM 对照阅读结论、否定范围、因果关系和条件从句。
