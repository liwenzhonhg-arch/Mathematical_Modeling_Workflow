# 科研绘图 Skill 前置实验 Spec

状态：实验规划已冻结，尚未形成正式 Skill。

## 目标

在不改变任何正式求解结果的前提下，建立一套可复算的科研绘图基准，用同一份
结构化数据比较 Matplotlib、MATLAB 和 Origin 的成图能力，为后续绘图 Skill 的
规则、模板、回退策略和评价样例提供证据。

## 范围

第一批覆盖八类数学建模常用图：

1. 时间序列与不确定性带。
2. 散点、拟合线与置信信息。
3. 原始点、分布和统计摘要组合图。
4. 分组数量比较图。
5. 顺序型或发散型热力图。
6. 敏感性 Tornado 图。
7. Pareto 前沿与被支配解。
8. 资源调度甘特图。

流程图、网络图、地图、物理场、分类诊断和 SHAP 图留到第二批，不得因为本轮
未覆盖而声明 Skill 已具备这些能力。

## 数据合同

- 所有输入由确定性脚本生成并保存为 CSV，不从参考论文图片反推数据。
- CSV 是三种后端共同的唯一数值来源；后端不得在绘图时改写输入。
- 每张图在 manifest 中记录图型、数据文件、字段、轴标签、单位和预期信息。
- 生成后记录输入 SHA-256；同一图的不同后端必须绑定相同输入哈希。
- 参考论文只提供表达方式和质量要求，不复制其数据、配色或版式。

## 输出合同

- 每个后端输出独立目录，至少保存 PNG；支持时同时输出 PDF 矢量图。
- Matplotlib 和 MATLAB 必须覆盖八类图。
- Origin 只对本机可稳定自动化的图型出图；不支持项必须写入报告，不能伪装成
  Origin 输出或静默复用其他后端图片。
- 所有正式输出使用白色背景，中文标题、坐标轴和单位必须可读。
- 实验产物不得进入正式比赛 `output/`、`.mmw/` 或发布包。

## 视觉原则

- 位置和长度优先于面积、体积和装饰性编码。
- 不使用彩虹色谱；顺序、发散和分类数据使用不同色图语义。
- 不仅依靠颜色区分系列，至少组合线型、点形、直接标注中的一种。
- 比较型图禁止 3D、阴影、渐变背景和无意义装饰。
- 柱状图基线默认从零开始；任何非零截断必须有显式理由和标记。
- 不确定性带必须注明含义，不能把标准差、标准误和置信区间混用。
- 图在最终论文栏宽缩放后仍须可读。

## 语义配色合同

首轮高饱和分类色仅用于能力验证，不进入后续 Skill。现役基准统一采用
`muted-editorial-v1`：低饱和海军蓝、陶土橙、灰青绿、灰紫和冷灰。精确色值及图型
映射保存在 `scientific_figure_benchmark/style_contract.json`，三后端不得各自使用软件
默认色板。

- 海军蓝只表达主方法、预测或有限候选前沿；陶土橙只表达对照、高扰动或拟合重点。
- 观测点、基线和被支配候选优先使用炭黑或冷灰，避免每个系列都争夺视觉焦点。
- 不确定性区间使用对应主色的低透明度浅带，不使用肉色或高饱和大面积填充。
- 发散热力图固定为低饱和蓝—米白—砖红，零值对应米白；不得调用软件默认
  `coolwarm` 或彩虹色谱。
- 分组柱图以明度和色相区分，取消密集交叉纹理；需要灰度交付时只添加稀疏纹理。
- 甘特图颜色绑定任务类别而非资源，同一类别跨资源保持同色。
- 坐标轴、正文和网格分别使用炭黑、炭黑和浅冷灰；上、右边框默认隐藏。

## 权威来源层级

1. 出版社/期刊正式图片规范：决定分辨率、字体、尺寸、格式和无障碍要求。
2. 可视化原始研究：决定图型选择、色彩、感知和不确定性表达。
3. 优秀论文实例：用于观察多子图组织、图注和领域表达，不自动提升为通用规则。
4. 软件官方文档：决定可自动化接口和导出能力。

完整来源矩阵保存在 `scientific_figure_benchmark/references.md`。

## 验收

- 八份标准 CSV 可由生成脚本重复产生，内容哈希保持一致。
- Matplotlib 和 MATLAB 各生成八张 PNG，且图像有效、尺寸达标。
- Origin 生成能力和失败项均有结构化记录，进程最终退出。
- 每张图的数据哈希、输出尺寸、格式和后端状态写入报告。
- 通过灰度可读、色盲友好、轴和单位、柱图零基线、色图语义等人工/自动检查。
- 不把“能生成图片”直接等同于“已达到论文质量”或“Skill 已完成”。

## 后续 Skill 边界

实验通过后才进入 Skill 草稿。Skill 必须包含触发条件、图型选择决策、数据合同、
后端路由、回退策略、质量门禁和评价样例。正式安装前按项目规则先运行
`/skill-vetter`，报告结果并等待用户确认。
