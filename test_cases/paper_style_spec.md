# 论文视觉规范 Spec

状态：已实现；A 题回归正确阻塞 `mmw-test` 与 `TEST-RUN`，正式队号仍需用户提供  
参考：`CMC2601940(1).pdf` 仅用于版式与图表风格，不读取其结论作为模型依据。

## 目标

把论文视觉要求变成可执行规则，避免 Writer 每次自行猜测格式。继续使用
`cumcmthesis`，不复制参考论文内容，也不突破 `config.yaml:max_pages`。

## 固定规范

- A4，正文单栏；首页依次为标题、队号/题号、摘要、关键词。
- 一级标题居中，二级和三级标题左对齐；禁止孤立标题落在页底。
- 正文、公式、表格和图注使用统一字号层级。
- 公式使用 `equation`/`align` 编号，禁止 `$$...\tag{}...$$`。
- 数据表优先三线表；符号表超过一页时允许分页，禁止缩到不可读。
- 图表居中，图注在下，表注在上；正文必须先引用后出现。
- 图表宽度只允许单栏宽、0.82 倍栏宽和双子图三档。
- 首页、正文和附录不得出现测试名、占位队号或缺失字符方框。

## 不做

- 不增加内容篇幅目标。
- 不修改模型、数值、结论和参考文献事实。
- 不把参考 PDF 的 76 页或其目录结构作为页数目标。

## 产物

- `mmw/latex/templates/paper_style.json`：程序可读取的尺寸与阈值。
- Writer、Typesetter 和质量门禁共享同一份规则。

## 验收

- 模板可被程序读取且字段完整。
- 当前 A 题首页不再显示 `mmw-test` 或 `TEST-RUN` 时才能正式交付。
- 缺失字符、超页、未定义引用和 LaTeX 错误均为硬失败。
