# 科研绘图基准人工视觉评审

评审日期：2026-08-11  
评审对象：`contact_sheet_matplotlib.png`、`contact_sheet_matlab.png`、
`contact_sheet_origin.png` 及各后端原始 PNG。

配色复审日期：2026-08-12。现役配色为 `muted-editorial-v1`，旧版高饱和蓝橙绿
分类色已退出现役基准。

## 结论

- **默认后端：Matplotlib。** 八类图的信息层次、系列区分、中文可读性和版式一致性最好，
  并且同一脚本同时输出 300 DPI PNG 与 PDF。
- **数值/工程计算联动后端：MATLAB。** 八类图全部成功，视觉结果接近 Matplotlib；适合
  数据和模型已经在 MATLAB 中产生的任务，但当前默认字号、图例和留白仍需统一模板。
- **可选精修后端：Origin。** 本机 COM/LabTalk 可以被调用并自动导出 300 DPI PNG；
  分组柱图结构和时间序列四条曲线可以导出，但分组色板未稳定接受。混合散点/曲线图层、Pareto 背景点，
  以及雨云图、热力图、Tornado、甘特图尚未达到自动化合同，不能作为默认后端。

## 配色复审结论

- Matplotlib 和 MATLAB 已统一为低饱和海军蓝、陶土橙、灰青绿、灰紫和冷灰；大面积
  区间带改为低透明度蓝灰，热力图改为蓝—米白—砖红，整体视觉焦点明显收敛。
- 分组柱图现以浅灰表示基线、海军蓝表示方法 A、陶土橙表示方法 B；Matplotlib 仅保留
  稀疏纹理，不再使用密集交叉纹理。
- Tornado、Pareto 和甘特图按数据语义分配颜色，而非循环套用分类色板。
- Origin 的单曲线/非分组图已接受新海军蓝和陶土橙；时间序列和分组柱图的分组样式属性
  未被当前 COM/LabTalk 会话稳定接受，因此继续标记 `degraded`，不能声称三后端完全同色。

## 八类图评审

1. **时间序列**：Matplotlib 与 MATLAB 的观测、预测和 95% 区间层次清楚；Origin
   只有四条曲线，区间含义不如半透明带直观，因此标记 `degraded`。
2. **散点拟合**：Matplotlib 与 MATLAB 保留原始点并突出拟合；Origin COM 混合图层
   未稳定保留观测散点，不能用于正式论文输出。
3. **分布组合图**：两个完整后端都同时展示原始点、密度和统计摘要，优于均值柱图；
   Matplotlib 的点、箱和密度层次更清楚。
4. **分组比较**：Matplotlib 用颜色加纹理提供双重编码，灰度适应性最好；MATLAB 和
   Origin 主要依赖颜色，需要后续模板补纹理或直接标签。
5. **发散热力图**：两个完整后端都以零为中点并显示色条；Matplotlib 的格点边界更清楚。
6. **敏感性 Tornado**：两个完整后端都围绕零基线排序；Matplotlib 的图例与参数标签
   更易读。
7. **有限候选 Pareto**：Matplotlib 与 MATLAB 明确区分被支配候选和当前前沿；Origin
   只稳定保留前沿，因此标记 `degraded`，且任何后端都不得把它称作全局前沿。
8. **甘特图**：两个完整后端都能显示资源、任务 ID、任务类别和空闲区段；Matplotlib
   的任务图例与标签更均衡。

## Skill 草案必须冻结的门禁

1. 图型先由数据语义选择，不能由用户指定的软件默认模板反向决定。
2. 每张图绑定输入 CSV 哈希；绘图阶段不得重算或修改正式数值。
3. 默认路由 `Matplotlib -> MATLAB（数据原生） -> Origin 白名单`；Origin 失败或降级时
   必须结构化记录并回退，禁止伪装成 Origin 输出。
4. Matplotlib/MATLAB 正式交付至少包含 PDF 矢量图和 300 DPI PNG；Origin 首轮只承诺
   经验证的 PNG。
5. 自动检查尺寸、DPI、文件签名、数据不变量和 Pareto 标记；人工检查最终栏宽、灰度、
   色觉缺陷、图例遮挡和中文字体。
6. 当前实验只覆盖八类图。流程图、网络图、地图、物理场、分类诊断和 SHAP 图进入
   第二批，不得提前宣称支持。
