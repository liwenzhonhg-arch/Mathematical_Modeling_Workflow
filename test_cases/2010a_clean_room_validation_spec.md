# 2010A 双工作区清洁盲测 SPEC

## 目标

在不向 Agent 泄露答案、参考代码或验收范围的前提下，用 2010 年 CUMCM A 题“储油罐的变位识别与罐容表标定”验证当前 MMW 是否能从题面与附件独立产出完整论文、代码、两张罐容表和可复核数值。

## 冻结对象

- 代码：启动首轮前记录当前 Git commit；两轮结束前不改代码、提示词、知识库和依赖。
- 题目来源：中国大学生数学建模竞赛官网 2010 年赛题压缩包。
- 输入转换：官方 `.doc/.xls` 仅通过 Microsoft Office 只读打开并另存为 `.docx/.xlsx`，不改正文、数据和文件名语义。
- 后端：本机既有 Codex CLI 登录态，进程内设置 `LLM_BACKEND=codex`，不读取或修改 `.env`。
- 每轮预算：`1,000,000 tokens`、`180` 活跃分钟、每阶段最多重做 `2` 次、总重做最多 `8` 次。
- 两个工作区：`workspace/benchmark_2010A_clean_r1`、`workspace/benchmark_2010A_clean_r2`。

## 隔离规则

每个工作区启动前只能存在 1 个题目 DOCX 和 2 个官方附件 XLSX；不得存在 `.mmw/`、`output/`、`references/`、旧检查点、旧论文、`reference_solver.py`、`reference_expected.json` 或任何预先计算结果。两个工作区不得互相读取。

## 独立 Oracle

`test_cases/2010A_储油罐变位/reference_solver.py` 只在流水线外运行，使用解析截面积与一维数值积分建立几何基线，并使用附件 2 前半段识别参数、后半段留出验证。它不得进入工作区、Agent 提示或普通检查点。

验收覆盖：

1. 问题 1：1 cm 罐容表覆盖、单调性、端点和抽样高度容积；倾斜进油数据误差。
2. 问题 2：纵向倾角绝对值、横向偏角绝对值、留出集 RMSE；10 cm 罐容表覆盖、单调性、端点和抽样高度容积。
3. 通用链：8 阶段质量门禁、结果新鲜度、方法契约、数值审计、论文编译、PDF 视觉门禁、最终导出。
4. 重复性：每轮 code 与 solve 结果一致；r1/r2 的参数和抽样罐容值在预声明容差内。

## 预声明容差

- `|alpha|`：`2.00°–2.30°`；`|beta|`：`4.00°–4.60°`。
- 附件 2 留出 RMSE：不超过 `20 L`。
- 问题 1 表格：高度覆盖至少 90%，严格非降；参考曲线抽样点最大绝对误差不超过 `150 L`。
- 问题 2 表格：高度覆盖至少 90%，严格非降；参考曲线抽样点最大绝对误差不超过 `100 L`。
- 同轮 code/solve：标量绝对误差 `1e-6` 或相对误差 `1e-8`。
- 跨轮参数：倾角绝对差不超过 `0.10°`；抽样罐容值相对差不超过 `1%` 且绝对差不超过 `100 L`。

## 停止规则

- 外部凭据、Codex CLI、token 或时长预算耗尽：记录为外部阻塞，不伪装完成。
- 任一质量门禁失败：允许托管器在冻结预算内重做；达到预算后停在真实失败阶段。
- 两轮基线结束前即使发现工具缺陷也只记录，不修改；修复须另开 post-fix 轮次。

## 产出

- `test_cases/2010A_储油罐变位/case.md`：两轮逐阶段事实与总判定。
- `test_cases/2010A_储油罐变位/gaps.md`：新增问题和改进顺序。
- `test_cases/2010A_储油罐变位/deliverables/r1|r2/`：最终成品与验收报告快照（仅在对应文件真实生成后复制）。
