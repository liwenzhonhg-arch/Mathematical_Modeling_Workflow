## 自主轮禁止操作

1. 不修改快照范围内任何文件。
2. 不人工编辑检查点产物、`solution.py`、`results.json`、LaTeX 或图表。
3. 不把优秀论文、评阅要点、题解或参考代码放入 `references/`。
4. 只允许使用 CLI 初始化、运行阶段、查看产物和审批；审批不得附带人工修改。
5. 阶段失败时保留原始证据，不修代码后继续冒充自主轮。
6. 允许系统内建的 Coder 反思重试和摘要迭代，因为它们是冻结版本的一部分。
7. 使用现有 `.env` 模型配置，不读取、打印或修改密钥。

## 三层结果

1. **自主版**：严格按上述禁止操作得到的首轮产物。
2. **辅助版**：自主版封存后，只允许人类提供方向、约束和验证意见，不直接代写模型或代码。
3. **最终版**：允许人工修改模型、代码和论文，形成可提交成品。
