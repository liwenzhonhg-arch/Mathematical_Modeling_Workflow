# 移动热模型最小可实现纪律 Spec

状态：**已实现，待下一轮真题回归（2026-07-29）**

## 问题

2020A r7 的 Modeler 为追求“完整”，连续加入置信域全域认证、题外全程单调性、
Hermite 全炉温场、互相冲突的验证分区和手写 Crank–Nicolson Robin 边界离散。
Verifier 每轮修掉旧问题又发现新问题，model 在 `800000` token 预算内无法通过。

## 规则

1. 模型只加入题面硬约束；未被题目要求的全程单调、严格稳健最优或连续置信域认证
   默认删除，不得拿它们改变可行域。
2. 移动热过程只定义连续 PDE、Robin 边界和受测数值模块接口，不在 LLM 文档中重新
   推导半控制体离散系数。
3. 环境温度以受控温区平台值为主体，只在真实间隙/边缘做单调过渡；不得用穿过温区
   中点的全域样条让整段平台偏离设定值。
4. 所有候选工况使用同一几何入口和炉外初态。观测若从温度事件开始，只允许把时间
   偏移作为基准实验对齐量；改变速度/设定后必须重新从入口仿真，不能迁移事件位置。
5. 参数不确定性只使用已有多起点可辨识性门禁和可执行的离散情景；没有严格区间算法
   时不得声称连续集合全域认证。
6. 验证集必须与数据支持相容。分区残差可作诊断，但不能同时要求单一尾窗覆盖互斥
   炉程区域。
7. 修订优先删除造成 block 的题外结构，不得为了修一个 issue 再增加新的验证层。

## 验收

- Modeler 与 revision prompt 明确包含以上最小化边界。
- 移动热知识条目与 prompt 一致。
- 自动测试证明关键纪律不会被后续改写删除。
- 下一次隔离真题回归在同等预算内减少 model 请求次数或通过 Verifier。
