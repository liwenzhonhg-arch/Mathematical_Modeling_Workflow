# 有效平板状态空间模型 SPEC

## 问题

连续 PDE 的扩散率与 Robin 参数可能在单条中心温度曲线上互相补偿；单状态或少量
串联状态又可能拟合原工况、却不能保持跨设定热记忆。两者失败后，不得靠隐藏答案、
扩大边界或增加任意时间偏移修正结果。

## 决策

允许使用不解释为材料参数的有效平板状态空间模型：

- 厚度方向使用固定奇数节点，内部节点由一个有效扩散率耦合；
- 两侧边界由少量设备区域组的有效交换率驱动；
- 受控温区之间的环境温度只在真实间隙线性过渡；末受控温区之后若为无设定温度的冷却通道，则按题面实际通道几何连续过渡到炉外温度，不把无控冷却区伪造成室温平台；
- 交换率在预声明的区域边界分段常数切换；
- 有效扩散率和交换率单位均为时间尺度参数，不称为真实热扩散率、换热系数或
  Robin 系数；
- 所有参数只从公开附件标定，不包含真题答案、Oracle 范围或参考实现常数。

运行时统一调用受测的 `simulate_effective_slab`，不得让 Coder 重写状态更新。

## 门禁

1. 至少 3 个不同初值，近最优参数及下游关键结果同时通过可辨识性诊断。
2. 显式内部扩散数与边界交换步长均保持稳定；不满足时直接失败。
3. 粗细时间网格复核只比较当前子问题实际使用的指标；不得用问题 3/4 的面积、
   对称性或平坦极值的任意 argmax 时刻阻断问题 2。
4. 跨速度和跨设定结果仍标记 `conditional_prediction`，
   `external_validation=unavailable`。
5. 合成数据必须能恢复已知有效参数；公开实现不写入任何真题专用常数。

## 验收

- 恒温平衡保持不变；
- 非法网格、非正交换率和不稳定显式步长被拒绝；
- 合成参数从多个初值恢复；
- Modeler、Coder、知识库与项目规则使用同一接口和证据边界。
