# TypesetterAgent Spec

状态：已实现；A 题先在 paper v23 验证违规输出拒绝，再在 v25 验证两轮契约修订通过

## 定位

TypesetterAgent 是 `paper` 阶段 Writer 之后的受约束修订步骤。它只编辑 LaTeX
结构和排版，不改变正文事实、公式含义、数值或引用来源。

## 输入

- Writer 生成的全部 `.tex`、`references.bib`。
- 当前图表 manifest。
- 论文视觉规范。
- 首次编译日志和视觉质量报告。

## 输出

- 排版后的同名 LaTeX 产物。
- `layout_report.json`：执行的确定性修正、warning 和失败项。

## 处理顺序

1. 确定性规范化：展示公式、图表路径、标题空白、连续空行。
2. 受约束 LLM 修订：只处理报告明确点名的章节。
3. 再编译并复查；最多两轮。

## 硬边界

- 修改前后从 `results.json` 可追溯的数值集合必须一致。
- 不得新增题目、方法、结果、引用或结论。
- 不得删除被正文引用的图表、公式标签和参考文献键。
- 仅允许 `sections/*.tex` 与 `references.bib`。
- LLM 输出不合规时丢弃该轮，保留上一版。

## 验收

- 数值保护、引用保护和文件白名单有测试。
- 当前 A 题的缺字、异常空白和图表布局问题能进入报告。
- 两轮后仍失败时明确阻塞 compile/export，不无限重试。
