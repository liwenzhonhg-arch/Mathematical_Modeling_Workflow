# 分区降阶温度响应模型 SPEC

## 问题

移动热过程的一维 PDE 在真实数据上可能能拟合轨迹，却无法同时辨识扩散率与
Robin 换热参数。此时继续放宽参数边界，或升级到需要题面未提供几何量的二维模型，
只会增加不可辨识参数，不能形成可执行证据。

## 决策

在物理 PDE 参数不可辨识时，允许退回以下有限、可标定的经验输入输出模型：

$$
\frac{\mathrm dT}{\mathrm dt}
=k_g(x(t))[T_{\mathrm{air}}(x(t))-T(t)],\qquad x(t)=vt.
$$

- $k_g$ 只按题面中不同设定值的受控炉区组及冷却区变化，不按每个小温区自由
  拟合，也不得无证据合并温度设定不同的受控组。
- $k_g$ 的单位是时间倒数，只表示中心温度的有效响应率；不得称为
  Robin 系数、材料参数或内部温度均匀性的证据。
- 观测时间使用题面定义的物理零点。附件从物理时刻 $t>0$ 才开始记录时，
  只在这些真实时刻比较，不再拟合任意时间平移。
- 当题面同时说明“进入设备开始计时”和“传感器达到某阈值后开始工作”时，后者
  只表示附件缺少阈值前的记录，不表示附件时间列在阈值事件处重新归零。
- 环境温度只由题面设定平台和真实间隙的线性过渡确定；经验降阶阶段不再同时拟合
  任意过渡形状参数，否则会把环境场误差转移给响应率并再次造成边界命中。
- 至少使用 3 个不同初值标定，报告边界命中、整体拟合、分区残差，并调用
  `assess_multistart_identifiability`。
- 只有拟合门槛和可辨识性门禁同时通过，才可用于同一设备、题面设定域内的
  条件预测与优化。
- 结论必须标注为“经验降阶/条件预测”，不得表述为材料参数辨识或跨设备验证。
- 若降阶模型仍不通过，必须返回结构化失败；不得引入题面缺失的板长、二维边界、
  额外时间偏移或题外硬约束。

## 运行时接口

受测模块提供：

```python
simulate_piecewise_first_order(
    sample_times,
    *,
    speed,
    air_position_knots,
    air_temperatures,
    response_position_knots,
    response_rates,
    initial_temperature,
)
```

`response_rates` 按位置线性插值，单位与 `sample_times` 的倒数一致；
`speed * sample_times` 必须与所有位置节点同单位。实现按每个采样间隔的中点环境
和响应率执行精确指数更新，不新增求解器依赖。

## 验收

1. 恒温且初温等于环境温度时输出保持不变。
2. 常数环境和常数响应率时，与解析指数解一致。
3. 合成分区数据可由至少 3 个不同初值恢复，并通过既有可辨识性诊断。
4. 负响应率、非递增时间或不相容输入被明确拒绝。
5. 提示词和知识库先尝试该有限降阶路径，不再要求缺少输入的二维升级。
6. 不把任何真题专用常数、参考答案或 evaluator-only 范围写入公开提示或知识库。
