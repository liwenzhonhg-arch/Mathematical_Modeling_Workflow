## 具体修改建议
1.  **摘要 (Abstract)**:
    *   建议将“result2 表中”改为“计算得到”。摘要中应避免引用正文中的表格编号，应直接陈述结果。
    *   “result2 表中覆盖宽度范围为63.05m--770.33m” 建议改为“覆盖宽度范围为63.05m至770.33m”，表述更规范。

2.  **符号说明 (Symbols)**:
    *   表格中“类型”一列，建议将“参数”、“中间变量”等更改为更标准的数学分类，如“已知常量”、“决策变量”、“状态变量”、“目标函数”等，使其更具学术性。

3.  **模型的建立与求解 (Model Solution)**:
    *   **子问题1**：
        *   在推导覆盖宽度公式时，可以增加一个简图辅助说明三角形各边、角的关系，使推导过程更直观。文字描述“$T$处张角为$\theta/2$；$P$处$PT$（竖直向上）与海底斜线的夹角，在上坡侧为$90^\circ-\alpha$、下坡侧为$90^\circ+\alpha$，故$Q$处角分别为$90^\circ - \theta/2 + \alpha$与$90^\circ - \theta/2 - \alpha$” 可以更简洁，例如直接给出三角形内角关系。
        *   重叠率定义中，`W_ref`取“两条测线中覆盖宽度的较小值”，这是一个合理的保守估计，但可以增加一句解释，说明为何这样定义（例如，为了确保重叠率不低于该值，防止漏测）。
    *   **子问题3**：
        *   贪心算法步骤2中，公式 `x_{i+1} = x_i + (W_i + W_{i+1})/2 * (1 - η_target)` 的推导逻辑可以更清晰。建议补充说明：`(W_i + W_{i+1})/2` 是相邻两条测线平均覆盖宽度的近似，乘以 `(1-η_target)` 得到的是不重叠部分的水平距离，从而确定下一条测线的位置。这种近似是合理的，但需要明确指出。
        *   算法描述中提到“通过迭代法求解”，建议简单说明迭代过程（如固定点迭代或二分法），以体现数学严谨性。

4.  **模型的检验——灵敏度分析 (Sensitivity Analysis)**:
    *   当前分析主要描述了“增减百分比”和“总长度增减百分比”的关系。建议增加一个**弹性系数**的定量分析。例如，“当坡度增加10%时，总长度增加38.24%，弹性系数约为3.8，表明总长度对坡度增加非常敏感”。这种量化分析能更深刻地揭示模型的敏感特性。
    *   图5、6、7的纵坐标可以统一为“测线总长度变化率(%)”，使比较更直观。

5.  **语言表达**:
    *   “问题1中”、“问题2中”等表述，建议统一修改为“在子问题1中”、“对于子问题2”等。
    *   “本文针对...问题，建立了...模型” 可以改为 “本文建立了...模型，以解决...问题”，语序更主动。
    *   检查全文，避免出现“我们”、“我们的”等第一人称复数，应使用“本文”、“模型”等客观表述。
