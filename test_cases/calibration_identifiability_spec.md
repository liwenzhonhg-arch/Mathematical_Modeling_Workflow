# 多起点参数可辨识性门禁 Spec

状态：**已实现（2026-07-29）**
制定日期：2026-07-29
适用范围：移动热过程及其他从单条观测曲线标定多个连续参数的 Coder 任务

## 1. 问题

2020A 结构辅助回归已证明：单次优化得到较低残差，不代表扩散率和分区换热参数
可辨识。不同初值可能得到近似相同损失、完全不同的参数和下游结论；任选一组继续
会让 solve 和论文建立在不可复现的模型上。

## 2. 目标

1. 在现有 `_mmw_moving_heat` 受测模块中提供通用多起点诊断，不增加依赖。
2. 至少使用 3 个不同初值；比较近最优解的参数跨度和可选下游指标跨度。
3. 返回可 JSON 序列化的诊断，包括原始初值、优化终值、损失、起点数、近最优数、
   相对跨度和失败原因，供流水线独立重算。
4. 一维瞬态导热代码必须调用该诊断，并在 `results.json` 写入
   `参数可辨识性` 状态，同时把完整报告写入结果目录的 `identifiability.json`；
   两份证据一致且通过时才能通过 code 门禁。
5. 不包含 2020A 答案、Oracle 范围或题目专用参数。

## 3. 判定

- 近最优解：损失不超过最小损失加相对/绝对容差。
- 参数相对跨度：同一参数近最优值的极差除以该列最大绝对值。
- 可选下游指标使用同样的相对跨度定义。
- 起点少于 3、近最优解少于 2、任一参数跨度超阈值或任一下游指标跨度超阈值，
  均判 `identifiable=false`。
- 非有限值、维度不一致、负损失或非法阈值直接拒绝，不返回伪诊断。

默认阈值只作为通用保守门禁：损失相对容差 1%、参数跨度 25%、下游指标跨度 5%。
调用方可按量纲和任务要求收紧，不能把阈值调宽来迁就失败结果。

## 4. 非目标

- 不替代剖面似然、Fisher 信息矩阵、Bootstrap 或贝叶斯后验分析。
- 不证明模型物理正确，也不证明现实可部署。
- 不读取隐藏 Oracle，不向 Agent 暴露参考答案。
- 不自动选择“最好看”的参数组。

## 5. 验收

- 合成多起点收敛到同一参数时通过。
- 相同损失对应明显不同参数时失败。
- 参数一致但下游指标明显不同时失败。
- 起点不足、NaN/Inf、维度错误和非法阈值被拒绝。
- 移动热任务缺少诊断调用、缺少状态项或状态为 0 时 code 候选被阻断。
- `pytest tests/test_moving_heat.py tests/test_stage_code_gate.py tests/test_coder_retry.py`
  与全量测试通过。
