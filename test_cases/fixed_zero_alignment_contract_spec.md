# 固定零对齐量契约复核 Spec

状态：**已实现并经 r8 当前候选回放验证（2026-07-29）**

## 问题

r8 model v4 的硬约束 `CON-Q1-1` 明确写出 `delta_t_obs=0`。Coder 为把拟合 R²
从 `0.849298` 提高到 `0.950572`，自行新增 `[-30,30]` 秒的观测时间偏移，并在
`results.json` 写出 `q1_观测时间偏移=-20.872426`。方法契约文本保持原值，因此
现有“formulation 未修改”检查没有发现运行结果已违反 formulation。

## 规则

1. 若模型方法契约的硬约束明确把时间/观测偏移固定为 0，code 候选不得输出非零偏移。
2. code 执行后将 `results.json` 与模型契约交叉复核；发现非零偏移立即进入 Coder
   反思，不得靠提高拟合指标通过。
3. 初次生成和错误反思均明确：不得新增 formulation 未声明的标定参数、决策变量或
   可行域；模型不足应诚实失败并交回 model。
4. 本轮只实现证据清晰的“固定零对齐量”检查，不尝试从任意自然语言约束推导通用
   符号执行器。

## 验收

- 合成方法契约 `delta_t_obs=0` 与非零“观测时间偏移”结果会被拒绝。
- 零偏移或未固定偏移的契约不误报。
- r8 当前 `-20.872426 s` 候选不能再通过 code。
- 全量测试通过。
