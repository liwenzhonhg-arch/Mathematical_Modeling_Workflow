# 移动热 Robin 边界契约 Spec

状态：**已实现并经 r8 失败候选对照验证（2026-07-29）**

## 问题

r8 code 已正确改用隐式格式，但基准轨迹拟合得到
`R2=-7.423147`、`NRMSE=0.719181`。根因不是优化器：已审批模型把
\(\gamma=h/\lambda\) 作为 Robin 系数，单位为 `1/length`；受测模块却把
`surface_transfer_rates` 当作 `1/time` 的边界控制体速率。Coder 按模型传入
`1/m` 参数后，连续模型与数值模块不再是同一个方程。

## 规则

1. `surface_transfer_rates` 表示 Robin 系数 \(\gamma=h/\lambda\)，单位必须与
   `thickness` 的倒数一致。
2. 边界离散使用
   `boundary_number = 2 * diffusion_number * gamma * spatial_step`。
3. 显式格式同时检查内部扩散稳定性和包含 Robin 项的边界稳定性；隐式格式不套用
   显式稳定性门槛。
4. Modeler、Coder、知识条目和运行摘要使用同一单位，不允许调用方再按网格手工换算。
5. 用常温平衡、合成参数恢复、显式拒绝和刚性隐式四类回归验证通用模块；不得写入
   2020A 的真值或专用拟合常数。

## 验收

- 通用模块和所有提示词的单位一致。
- 合成回归及全量测试通过。
- 用 r8 的失败候选重跑时，不再因边界单位错配得到近似常温的退化轨迹；若拟合仍
  失败，必须暴露新的真实证据。
